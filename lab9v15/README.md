

 Опис реалізації підзадач

Згідно з варіантом 15, реалізовано систему `NotificationSystem`:
1. **HashSet<string>** — зберігає унікальних користувачів (`_subscribedUsers`), що увімкнули сповіщення. Забезпечує відсутність дублікатів при підписці (складність `O(1)`).
2. **Queue<Notification>** — черга сповіщень (`_notificationQueue`). Реалізує принцип **FIFO** (First In, First Out). Нові сповіщення додаються в кінець (`Enqueue`), а обробляються з початку (`Dequeue`). Також використано `Peek()` для попереднього перегляду.
3. **Stack<Notification>** — історія оброблених (прочитаних) сповіщень (`_notificationHistory`). Реалізує принцип **LIFO** (Last In, First Out). Додається на вершину (`Push`), видаляється/скасовується остання дія з вершини (`Pop`). 
         Відповіді на контрольні запитання
1. У чому різниця між List та HashSet?List<T> зберігає елементи у певному порядку (за індексом) і дозволяє дублікати. Пошук елемента в ньому займає $O(N)$. HashSet<T> — це неупорядкована колекція, що зберігає лише унікальні елементи. Пошук, додавання та видалення в HashSet у середньому виконуються за $O(1)$.
2. Коли доцільно використовувати Queue замість List?Queue<T> доцільно використовувати, коли потрібна строга дисципліна обробки FIFO (Першим прийшов — першим пішов), наприклад, для черг завдань, буферів, обробки подій або алгоритму BFS (пошук в ширину). Queue оптимізовано саме для додавання в кінець і видалення з початку.
3. Наведіть приклад реальної задачі, де потрібен Stack.Stack<T> ідеально підходить для реалізації функції скасування дій (Undo) у текстових/графічних редакторах, для відстеження історії навігації (кнопка "Назад" у браузері), а також в алгоритмах обходу дерев і графів (DFS - пошук в глибину) чи парсингу математичних виразів.
4. Яка складність операції Contains() для HashSet і чому?
Складність в середньому становить $O(1)$ (константний час). Це пояснюється тим, що HashSet<T> побудований на основі хеш-таблиці. Для пошуку елемента обчислюється його хеш-код, який одразу вказує на "кошик" (бакет), де має знаходитись елемент, тому не потрібно перебирати всю колекцію.5. Чому Queue називають FIFO, а Stack — LIFO?FIFO (First In, First Out) для Queue<T> означає, що елемент, який був доданий у чергу першим, першим і буде з неї вилучений (як звичайна черга в магазині).LIFO (Last In, First Out) для Stack<T> означає, що останній доданий елемент буде вилучений першим (як стопка тарілок: ми беремо верхню, яку поклали останньою).
