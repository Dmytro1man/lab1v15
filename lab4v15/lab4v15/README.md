  Мета роботи
Ознайомитися з принципами наслідування, віртуальними методами (`virtual`), їх перевизначенням (`override`) та приховуванням (`new`) у мові C#.



  Хід роботи
1. Створено базовий клас `Clothing` із властивостями `Material`, `Size` та віртуальним методом `Wear()`.
2. Створено похідні класи:
   - `Shirt` (додано властивість `SleeveLength`, перевизначено `Wear()`, додано `new GetClothingType()`).
   - `Pants` (додано властивість `WaistSize`, перевизначено `Wear()`).
3. У файлі `Program.cs` продемонстровано роботу поліморфізму через масив базового типу `Clothing[]` та різницю між `override` і `new`.
4. Проєкт успішно зібрано та завантажено на GitHub.



  Контрольні запитання

1. **Що таке наслідування і для чого воно використовується?**
   > *Відповідь:* Наслідування дозволяє створити новий клас на основі існуючого, успадковуючи його властивості та методи, що запобігає дублюванню коду.

2. **Яка різниця між `override` та `new` при перевизначенні методів?**
   > *Відповідь:* `override` змінює поведінку методу за допомогою динамічного поліморфізму (через посилання базового типу викличеться метод похідного класу). `new` лише приховує метод базового класу (через посилання базового типу викличеться старий метод базового класу).

3. **Що означає модифікатор `virtual`?**
   > *Відповідь:* Модифікатор `virtual` у базовому класі дозволяє перевизначати цей метод у похідних класах за допомогою ключового слова `override`.
