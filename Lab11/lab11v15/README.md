 Опис реалізації

У цій лабораторній роботі реалізовано сценарій управління комп'ютерами та їхніми компонентами.
- **Сутності:** `Computer`, `Component`, `Specification`. Вони утворюють багаторівневу вкладеність: комп'ютери містять список компонентів, а компоненти — список характеристик[cite: 27].
- **Тестові дані:** Створено 3 комп'ютери, які містять 8 компонентів та 16 унікальних характеристик загалом.
- **SelectMany:** Реалізовано "розгортання" колекції колекцій. Запит `computers.SelectMany(c => c.Components).SelectMany(comp => comp.Specifications)` збирає характеристики з усіх рівнів в один плоский список[cite: 25, 27].
- **Пагінація:** Список усіх компонентів виводиться посторінково з розміром сторінки у 4 елементи. Для цього застосована комбінація методів `.Skip()` та `.Take()`[cite: 27].
- **Custom Extension Method:** Створено метод розширення `GetSpecification(string key)` безпосередньо для доменної сутності `Component`. Він дозволяє безпечно витягувати значення конкретної характеристики за ключем без дублювання коду перевірки на `null`[cite: 27].


 Відповіді на контрольні питання

**1. Для чого використовується оператор SelectMany? Наведіть приклад, що демонструє його відмінність від Select.**
Оператор `SelectMany` використовується для проекції елементів колекції в нову колекцію з подальшим об'єднанням (flattening) цих вкладених колекцій в одну плоску послідовність[cite: 25]. 
*   Якщо використати `computers.Select(c => c.Components)`, ми отримаємо тип `IEnumerable<List<Component>>` (список списків).
*   Використавши `computers.SelectMany(c => c.Components)`, ми отримаємо тип `IEnumerable<Component>` (плоский список усіх компонентів з усіх комп'ютерів).

**2. Як реалізувати пагінацію даних за допомогою LINQ? Які методи для цього використовуються?**
Пагінація реалізується за допомогою розбиття набору даних на керовані сторінки[cite: 25]. Для цього використовуються два методи:
*   `Skip(n)` — пропускає вказану кількість елементів `n` з початку колекції. Формула пропуску: `(номер_сторінки - 1) * розмір_сторінки`.
*   `Take(m)` — бере наступну задану кількість елементів `m` (розмір сторінки).

**3. Поясніть концепцію методів розширення. Як вони інтегруються з LINQ?**
Методи розширення (Extension Methods) дозволяють додавати нові методи до існуючих типів даних, не змінюючи їхнього вихідного коду і не використовуючи спадкування[cite: 25]. Вони оголошуються як статичні методи в статичних класах, де перший параметр позначається ключовим словом `this`. Весь LINQ (наприклад, `Select`, `Where`, `SelectMany`) побудований саме на методах розширення для інтерфейсу `IEnumerable<T>`.

**4. Наведіть приклад власного методу розширення для IEnumerable<T> та поясніть його призначення.**
Приклад методу, який рахує кількість елементів у колекції, що відповідають певному критерію, і повертає результат у форматі рядка:
```csharp
public static class EnumerableExtensions
{
    public static string GetCountMessage<T>(this IEnumerable<T> source, Func<T, bool> predicate)
    {
        int count = source.Count(predicate);
        return $"Знайдено {count} елементів, що відповідають умові.";
    }
}
